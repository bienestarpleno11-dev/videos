🔑 Conexión para publicar

El contenido de la app se guarda en tu GitHub (repositorio “videos”). Publicar es gratis y no gasta créditos de Netlify. Para eso el Estudio necesita un token de GitHub, que se guarda solo en este dispositivo.

  1. Entrá a GitHub → Fine-grained tokens → Generate new token con la cuenta bienestarpleno11-dev.
  2. Nombre: “Estudio”. Vencimiento: el que quieras (por ejemplo 1 año).
  3. En Repository access elegí Only select repositories → videos.
  4. En Permissions → Contents elegí Read and write.
  5. Tocá Generate token, copialo y pegalo acá.
